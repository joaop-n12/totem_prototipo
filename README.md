# 📘 Totem FlexMedia

## 🎯 Objetivo
Criar um protótipo de totem inteligente interativo em Python para oferecer informações educativas, culturais e de lazer, permitindo o cadastro e listagem dessas informações diretamente no terminal.

---

## 📦 Entrega da Sprint 1: Funcionalidades

Nesta primeira etapa, o programa em Python (`totemflexmedia.py`) possui as seguintes funcionalidades:

* 🏠 **Menu Interativo:** Navegação simples entre as opções.
* 📝 **Cadastro de Informações:** Permite registrar dados de `Título`, `Tipo` (com validação de tipos permitidos) e `Descrição`, armazenados em uma lista de dicionários.
* 📄 **Listagem Estilizada:** Exibe todas as informações cadastradas de forma organizada, utilizando cores para destaque.
* 🔁 **Fluxo Contínuo:** Permite cadastrar ou listar informações consecutivamente através de um laço `while`.
* 📊 **Controle de Dados:** Implementa um contador para mostrar o número total de informações registradas.

## 🛠 Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Estilização:** Códigos ANSI para cores no terminal
