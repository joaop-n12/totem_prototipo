## 📘 Totem FlexMedia

## 🎯 Objetivo
Criar um protótipo de **totem inteligente interativo em Python.**

## 📦 Entrega desta Sprint 1
Será criado um **programa em Python** com:
- Um **menu inicial**
- Funções para **cadastrar** e **listar** informações

O programa usará **listas, estruturas de decisão (if/else), laços de repetição (while)** e **funções**, aplicando os conceitos aprendidos em sala de aula.
